# 💰 SpendWise – Python Expense Tracker

**Track Your Expenses, Manage Your Money, Spend Wisely!**

SpendWise is a simple console-based Expense Tracker developed using Python. It helps users record their daily expenses and monitor their total spending.

## 🚀 Features

- Add daily expenses
- Record expense details
- View recorded expenses
- Calculate total spending
- Simple console-based interface

## 🛠️ Technologies Used

- Python 3
- Conditional Statements
- Loops
- Python Data Structures


## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/chirag050678/Expense-Tracker-Python.git
```

2. Open the project folder:

```bash
cd Expense-Tracker-Python
```

3. Run the program:

```bash
python main.py
```

To develop a basic expense management application while learning Python programming concepts and practical problem-solving.
